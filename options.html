Protected URLs

URL Gate asks for Touch ID before opening the URLs listed here. Saving also requires Touch ID.

How to write URLs

  • example.com/admin: asks for Touch ID before opening this page and the pages under it.
  • !example.com/admin/help: a line starting with ! is an exception, which opens without Touch ID.
  • * matches any string (*.example.com). Lines starting with # are comments.

For everything else you can write, see the full syntax.
